// capabilities

Everything you need to run an AI workforce

A batteries-included platform — from agent orchestration to enterprise governance — so you can focus on building, not plumbing.

Autonomous Agents

12 built-in agent types — Planning, Research, Analysis, Coding, Execution, and more — with circuit-breaker retry logic.

CrewAI Orchestration

Multi-agent crews with role assignment, task dependencies, and parallel execution via LangChain pipelines.

Conversational AI

Session-persistent conversations with intent classification, sliding context windows, and automatic agent routing.

Task Queue

Redis-backed (with asyncio fallback) task queue with SSE streaming, priority levels, dead-letter handling, and persistence.

Enterprise Security

JWT + API key auth, RBAC with 4 built-in roles, multi-tenant isolation, and immutable SQLite audit logs.

Workforce Management

Hire/fire workers, assign objectives, auto-scale by agent type, and monitor pool utilisation in real time.

Hybrid Memory

Short-term in-process memory, long-term ChromaDB vector search, and episodic recall across agent invocations.

Observability

Prometheus metrics at /metrics, OpenTelemetry tracing, structured JSON logs, and per-key rate limiting.
